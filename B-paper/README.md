# 2026 全国大学生数学建模竞赛 B 题 —— LaTeX 论文工程

本工程为 **B 题（无线电干扰源的快速自动定位与清除）** 的论文框架，正文均为占位，
可直接编译出 PDF。已按 2026 年规范配置，并完成整体排版紧凑化。

> 填充正文前请先读 **`FORMAT-GUIDE.md`**（格式红线 + 排版注意点 + 写作约定）。

## 快速开始

```bash
cd B-paper
bash build.sh      # XeLaTeX 连跑两遍 + 缺字/错误自检
```

## 编译

模板**必须使用 XeLaTeX**（不能用 pdfLaTeX）：

```bash
cd B-paper
bash build.sh                                # 推荐：两遍编译 + 自检
# 或手动：
xelatex main.tex && xelatex main.tex         # 连跑两次更新交叉引用
```

> 首次编译时 MiKTeX 可能提示自动安装缺失宏包，选「允许」即可。

## 2026 格式要点（已配置）

| 要点 | 说明 | 处理 |
|---|---|---|
| 电子版首页 | 第一页必须为**摘要专用页** | `\documentclass[withoutpreface]{cumcmthesis}` |
| 承诺书/编号页 | **不得**出现在电子版 | `withoutpreface` 已去除 |
| 摘要 | 含标题+关键词，无需英文，≤1 页 | 已实现 |
| 页码 | 从摘要页起、页脚中部、从 1 编号 | 模板默认 |
| 正文 | 不要目录，≤30 页 | 未加目录 |
| 附录 | 含支撑材料文件列表 + 全部源程序 | 见 `08-appendix.tex` |
| 匿名 | 摘要/正文/附录不得出现身份信息 | 占位内容均无身份信息 |
| 文件 | 单个 PDF，≤20MB，不压缩 | —— |

## 紧凑化排版（已配置，集中 `main.tex` 顶部）

| 项 | 值 |
|---|---|
| 正文行距 | 1.25（模板默认 1.38） |
| 三线表行距 | 1.0 |
| 列表顶部间距 | 0 |
| 章节标题前后距 | 已收紧 |
| 行间公式上下距 | 8pt |
| 图表标题（caption）间距 | above 4pt / below 2pt |
| 浮动体与正文间距 | textfloatsep 8pt / floatsep 6pt / intextsep 6pt |

恢复模板原样：删除 `main.tex` 顶部「排版紧凑化」整块即可。
