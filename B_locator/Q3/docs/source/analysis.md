# A 题：药材的烘干问题

**本质**：圆柱（长 25 cm、半径 2 cm）在热风烘房中的一维（径向）传热与传质耦合问题。

| 问 | 内容 | 难度 |
|---|---|---|
| 1 | 预热平衡阶段温度场 + 水分浓度场，1800 s，输出 1 s × 0.1 cm | ★★★☆☆ |
| 2 | 整个 2–3 天过程，温湿强耦合、参数随 C、T 变化 | ★★★★☆ |
| 3 | 求各处水分浓度 < 0.15 kg/kg 的**停止时间** | ★★★☆☆ |
| 4 | 药材尺寸随失水收缩（半径 2.0 → 1.198 cm），**移动边界** | ★★★★★ |

**关键难点**

1. **两个场互相耦合、且都是非线性的**。附录 3 给出 ρ=650+128C、c_p=1450+2736·C/(C+1)、k=0.21+0.38·C/(C+1)，而 D=2.4×10⁻³·e^(−0.45C)·e^(−3850/T) 是**温度与浓度双指数**：温度从 301 K 升到 323 K，D 变化约 e^(−3850/301+3850/323) ≈ 2.4 倍。传热决定 D，D 决定失水，失水又改变 ρ、c_p、k——**必须交替迭代或整体隐式求解**。
2. **边界条件不对称**。温度是第三类边界（h=25 W/(m²·K)，还有 ρ、c_p 参与），水分是第三类传质边界加 **D 依赖于表面浓度**，形成强非线性边界，显式格式几乎必然振荡，得用隐式/半隐式 + 不动点迭代。
3. **圆柱坐标原点奇异**。控制方程在 r=0 有 (1/r)·∂/∂r(r·D∂C/∂r)，必须用洛必达法则或控制体积法处理，直接差分会除零。
4. **量纲陷阱**：干基含水率 C（kg/kg，初始 **2.55**）与体积浓度（kg/m³）必须严格区分。注意附件 1 给的是**烘房环境**的水分浓度（0.0196–0.0503 kg/kg），不是药材自身的含水率——很多人第一步就会理解错。
5. **问题 4 是真正的分水岭**。收缩意味着：
   - 边界 r=R(t) 在移动，网格必须重划或做坐标变换（Landau 变换 ξ=r/R(t)），变换后会**多出一个对流项和度量因子**；
   - 需要用"干物质质量守恒"而不是简单的 ∂C/∂t = ∇·(D∇C) 来写方程；
   - 收缩与失水通量耦合，附件 2 只有 30 min 一个点（0→259200 s 共 145 点），而输出要求 **60 s**，需要插值 + 一致性说明；
   - 收缩假设（体积线性收缩 / 保干物质）需自证，**没有标准答案**，评委看的就是建模严谨性。
6. 数据只有 **241 个点（60 s 间隔，4 小时）** 用于标定环境温湿度变化；2–3 天阶段要靠经验公式外推，外推合理性是隐藏考点。

**坑点清单**：r=0 奇异、非线性隐式格式稳定性、干基/湿基含水率、问题 3 停止时间对扩散系数的敏感性（建议做灵敏度分析，否则几小时的偏差说不清）、result1–4 的稠密表格格式（1 s × 0.1 cm，四位小数）。

# B 题：无线电干扰源的快速自动定位与清除

**本质**：这不是数学难题，而是一道**算法工程 + 实时系统**题。

| 问 | 内容 | 难度 |
|---|---|---|
| 1 | 示向度交会定位区域直径；该直径圆能否覆盖定位区域 | ★★☆☆☆ |
| 2 | 第二检测点选择策略与候选区域 | ★★★☆☆ |
| 3 | 1800 m 圆域、10–16 个未知全向源、20 min 现实时间内全部清除 | ★★★★★ |
| 4 | 叠加定向干扰源（方向未知） | ★★★★★ |

**关键难点**

1. **问题 1 是送分的几何题**。两条示向度各带 ±1° 锥，交会出四边形；求任意两点最大距离即求凸包直径（旋转卡壳）。第二小问的答案通常是**不能覆盖**——直径圆的圆心在区域外或区域内，而细长四边形的最小球覆盖半径可能小于半直径，构造反例即可。这里能体现几何功底，但难度不高。
2. **问题 2 有真正的建模味道**：示向度误差 ±1° 在距离 d 处造成横向误差 ≈ d·(π/180)，所以"离得近"和"交会角接近 90°"要权衡。用 Fisher 信息矩阵 / GDOP / 误差椭圆把它形式化，再给出候选区域（等精度线或扇环），属于**最优实验设计**思想，是本题唯一有理论美感的地方。
3. **问题 3 是主战场，时间约束的"口径"是最容易搞错的一点**（我们已经在正式模拟器上踩过）：
   - **现实时间**：`/enter` 后最长 20 min = 1200 s，且必须在 25 min 窗口开启后 5 min 内进入；
   - **虚拟时间**：上限是 360000 s（100 小时），`/measure` 固定 5 s、换频道 +1 s、移动 5 m/s，
     `/clear` 未发现 3 s、成功 5 s —— 这些只累计**虚拟时钟**，与 1200 s 的现实预算**无关**。
     模拟器不会为了虚拟时间真的等待，所以一局墙钟通常只有几秒（我们实测 2.7–6.5 s），
     而虚拟时钟能走到 5000–7000 s。**把 1200 s 当成虚拟时间上限会让离线演练完全失真**
     （我们的离线清除率因此从 0.995 被压到 0.415）。
   - 于是真正的指标口径是：**在现实 1200 s 内尽可能多清、且虚拟时间（= 平均定位清除时间的分子）尽量小**。
     我们线上实测：10/10 与 14/14 全部清除，平均定位清除时间 239.5 s（新参数）/ 642.9 s（旧参数）。
   - 有效的关键洞察：**频道只有 20 个且互不相同**，同一频道只需定位一次；应当先粗扫建立
     "频道→射线束"台账，再对交会区域收敛的频道做精定位。本质是**信息驱动的旅行商问题
     （TSP with active sensing）**，可用栅格/正六边形铺排路线 + 射线交点置信椭圆修剪。
   - 实测最大的两块浪费：① "场上一条方位都没有"的空场阶段会退化为就近蹭点（占 45%）；
     ② 清完所有源之后算法无法确知"已经清完"，会继续空转（占 37%）。
4. **协议陷阱很多**（附件 2 明文规定，很容易踩）：
   - 未声明的 JSON 字段**不会报错**，而是返回 HTTP 200 + `accepted=false`，动作**不执行**——拼错字段名会静默失效；
   - 每个新动作必须新 `request_id`；重试必须复用原 `request_id`，否则同 ID 改内容返回 409；
   - 必须**串行**发送，不得并发；必须同时检查 HTTP 状态 **和** `accepted`；
   - `accepted=false` 时 `virtual_time_s` 返回 0，**不能**当作当前时刻；
   - `/clear` 的 channel 不切换测向机频道、不产生切换耗时（易算错时间）；
   - `remaining_real_duration_s` 是动态的（0–1200），不能硬编码 1200。
5. **风险等级最高**。正式测试只有 3 次，模拟器随机出题，需要**在线登录 + 服务器时间校验 + 全程联网**，北京时间 2026-09-13 17:30 后不能再开新测试（建议 15:30 前完成）。网络抖动、程序卡死、死循环都会直接消耗一次机会。问题 4 加了定向源后，"测不到信号"有三种截然不同的原因（无该频道 / 超有效接收半径 1000–1500 m / 在定向覆盖角外），诊断逻辑复杂度陡增。

**结论**：数学新意低，但**实现难度和翻车风险最高**，且成绩高度依赖模拟器实测指标（清除比例、平均定位清除时间）。表 1 的"程序运行时间"也是评分点之一。

# C 题：微网与外部电网电力调控策略

**本质**：带储能套利的能量调度优化问题，逐问升级。

| 问 | 内容 | 难度 |
|---|---|---|
| 1 | 电价/负载每日重复，给光伏预测，制定全天购电计划 | ★★☆☆☆ |
| 2 | 负载/光伏时变，缺电需 5 倍电价紧急购电 | ★★★☆☆ |
| 3 | 0/6/12/18 时四次预报，计划外调整有违约罚（0.5×）和溢价（1.5×） | ★★★★☆ |
| 4 | 电价实时波动，重做问题 2、3 | ★★★★★ |

**关键难点**

1. **问题 1 是标准 LP**。决策变量：每 10 min 的购电量 g_t、充电 ch_t、放电 dis_t、弃光 u_t（144 期 × 4 ≈ 576 个变量/天）。约束：功率平衡、储能荷电状态递推、容量 12000 kWh、SOC 限 1200–10800 kWh、充放电功率 5000 kW、效率 0.9、**0:00 与 24:00 储电量相同**。HiGHS 秒解。
   *（我实测：附件 1 当天最大净负荷 7612 kW、峰值电价 1.3952 元/kWh、谷值 0.3713 元/kWh，日内净购电需求约 5.55 万 kWh；储能可带来千元级至万元级的日节省，性价比完全由 η 与峰谷价差决定。）*
2. **问题 2 引入 5 倍紧急电价**，看似加惩罚，实则结构性变化：最优解会自动预留 SOC 作为**备用容量**。约束的**对偶变量（影子价格）**可以给出"备用电量值多少钱"的漂亮解释——这是低成本高分的加分点。
3. **问题 3 是本题真正的门槛，也是最能拉开差距的地方**。它不再是单阶段确定性问题：
   - 决策变量按信息结构分层 → 两阶段 / 多阶段**随机规划**，或滚动时域（MPC）优化；
   - 计划量与实际量的**方向性惩罚**（少买 1.5×、多买 0.5×违约）是非对称损失，需要用分段线性化拆成两个非负偏差变量；
   - 题目**明确要求分析"是否需要引入其他时刻的预报"**——这是 **VOI（信息价值）**问题：比较 1 次/2 次/4 次预报下的期望总成本，用数据说话。多数队伍会含糊带过，做扎实就能拉开。
4. **问题 4 最难，因为没有未来电价预报**。附件 4 只给历史实时电价，你必须：
   - 建立电价预测/场景生成模型（时间序列、场景树），或
   - 采用**鲁棒优化 / 在线学习（如在线凸优化、Lyapunov 漂移加惩罚）**，并讨论 regret 或保守度；
   - 并说清与问题 2、3 的差异（附件 2 的负载与光伏、附件 3 的预报、附件 4 的电价，四份数据的对齐与滚动机制）。
5. **数据量与工程细节是隐形门槛**：
   - 附件 2/4 各 **365 天 × 144 点**（约 5.3 万格），附件 3 为 **1460 行 × 24 小时预报**，全部要按"日期 × 0/6/12/18 发布"正确对齐；
   - 附件 2 列头是 `00:10 … 0:00+1` 共 144 列，**首列标题写作 00:10 实际是 0:00 结束的区间**，索引错位会导致整份 result 系统性偏差；
   - 输出体量最大：result2/3/4 每个都是 335 行 × 147 列级别，`结果模板必须逐格对齐` 是最容易失分处；
   - 循环约束（0:00 与 24:00 储电量相同）在 334 天连续调度下要处理边界一致性。

**结论**：模型不会"崩"，结果可自验，是三题中**最稳妥、最容易做出完整论文**的一题；代价是选题人数多，需要靠问题 4 的建模深度、对偶/灵敏度分析和排版规范取胜。
