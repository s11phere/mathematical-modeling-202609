## 数据格式约定（来自题目正文附录 1/2 与模拟器接口说明）

| 项 | 约定 |
|---|---|
| 坐标系 | 米；(0,0) 为半径 1800 m 圆域中心；x 轴正东、y 轴正北 |
| 方位角/示向度 | x 轴正向逆时针为正，范围 [0°,360°)，单位度，**保留两位小数** |
| 示向度误差 | [-1°, 1°]；同一地点误差固定，换地点才变 |
| 频道 | 1..20 整数，每频道最多一个干扰源；干扰源总数 10–16 |
| 有效接收半径 | 1000–1500 m，逐干扰源不同，**接口不返回** |
| 定向源覆盖 | 定向方向两侧各 90°（含边界） |
| 近场阈值 | 5 m（返回 `near`，不给示向度） |
| 清除半径 | 20 m（与定向朝向无关） |

接口中"检测点 + 示向度"的实际形态：

```json
POST /measure
{ "arena_id":"default", "robot_id":"<队号>", "request_id":"m1",
  "position": {"x": 300, "y": 400}, "channel": 1 }

→ { "accepted": true, "real_timestamp_ms": 1760000000000,
    "virtual_time_s": 105, "measure_result": "direction", "svd_deg": 123.45 }
```

问题 1、2 的"输入"就是若干组 `(x, y, svd_deg)`；问题 3、4 的"输入"是接口返回流。

**生成器要点**：检测点必须"良态"——分布在干扰源四周一定方位张角内（默认 ±70°）、
最小方位间隔 ≥ 25°、距离 ≥ 150 m。否则各示向度锥近似平行，定位区域会退化成
细长或无界区域（这不是算法错，而是场景病态）。

## 问题 1 参考实现与结果

```bash
python src/p1_intersection.py ./data
python tests/selftest_p1.py      # 端到端不变量自检
```

算法：每条示向度展开为 ±1° 的角楔 → 区域边界必为 2k 条边界线的交点 →
枚举 O(k²) 个交点、用"到各示向度的角差 ≤ 1°"筛选 → 凸包 → 暴力枚举最远点对求直径。

在 5 个自造算例上的结果：

| 算例 | 顶点数 | 直径 D (m) | 直径圆覆盖定位区域 | 圆心距真值 (m) |
|---|---|---|---|---|
| case01 | 6 | 17.64 | 是 | 3.67 |
| case02 | 5 | 18.61 | **否** | 3.57 |
| case03 | 4 | 25.64 | **否** | 3.68 |
| case04 | 5 | 21.12 | 是 | 1.53 |
| case05 | 6 | 10.59 | 是 | 1.42 |

**结论**：以定位区域直径为直径的圆，**不能保证覆盖该定位区域**（5 个算例中 2 个反例）。
注意这是"不保证"而非"必然不能"——某些几何构型下恰好能覆盖，所以论文里应给出
判定算法 + 反例，而不是一句"不能"。

## 自检不变量（tests/selftest_p1.py）

- I1 真值必须落在定位区域内
- I2 定位区域为凸多边形
- I3 直径 = 暴力枚举的最远点对距离（全精度一致）
- I4 直径圆覆盖判定与 `max顶点距 ≤ D/2` 一致
- I5 直径量级合理
