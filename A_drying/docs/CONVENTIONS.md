## 3. 建模约定（单位与符号，全局统一）

| 符号 | 含义 | 单位 |
|---|---|---|
| $r$ | 到药材中心的距离（径向坐标） | m（内部）；cm（输出） |
| $t$ | 时间 | s（内部）；h（论文表格） |
| $T(r,t)$ | 药材温度 | K（内部）；°C（输出） |
| $T_\infty(t)$ | 烘房温度 | K |
| $C(r,t)$ | 药材水分浓度，**干基含水率** kg 水/kg 干物质 | kg/kg |
| $C_\infty(t)$ | 烘房水分浓度（空气绝对湿度，干基） | kg/kg |
| $R(t)$ | 药材半径（问题 4 中随时间收缩） | m |
| $\rho,\ c_p,\ k$ | 药材密度、比热容、导热系数 | kg/m³、J/(kg·K)、W/(m·K) |
| $D$ | 水分扩散系数 | m²/s |
| $h$ | 对流换热系数 | W/(m²·K) |
| $h_m$ | 对流传质系数 | m/s |
| $L$ | 水的汽化潜热 | J/kg |

**约定 D1（干基 vs 湿基，易错点）**：
题目、附录明确 $C$ 为**干基含水率**（kg/kg 干物质），初始 2.55 kg/kg。
`附件1` 的"水分浓度"是**烘房空气**的绝对湿度（0.0196→0.0500 kg/kg），**不是药材含水率**，两者量纲相同但物理对象完全不同，绝不可混用。

**约定 D2（密度基准）**：附录给的 $\rho$ 是**表观湿密度**（kg 湿药材/m³）。
干物质表观密度由干物质守恒给出
$$\rho_d=\frac{\rho}{1+C}.$$
在无收缩问题中 $\rho_d$ 为常数；在收缩问题中 $\rho_d$ 随 $R(t)$ 变化，由
$$\rho_d(t)\,R(t)^2=\rho_d(0)R(0)^2=\text{const}$$
确定（单位长度圆柱的干物质质量守恒）。

**约定 D3（传质驱动势）**：表面传质通量取
$$j_w=h_m\big(\rho_d C\big|_{r=R}-\rho_{\text{amb}}\big),\qquad \rho_{\text{amb}}=\rho_d C_\infty .$$
即把烘房湿度 $C_\infty$ 换算成与药材内部同一体积基准的浓度后作差。这是本题唯一自洽的写法：
$h_m$ 的单位 m/s 要求驱动势与被求通量同为 kg/m³。该选择在 `docs/MODEL.md` 中做了量纲与敏感性说明。

**约定 D4（能量方程的潜热耦合）**：表面热平衡**必须包含汽化潜热项**，否则温度会严重高估：
$$-k\frac{\partial T}{\partial r}\Big|_{R}=h\big(T_\infty-T\big|_{R}\big)-L\,j_w .$$
本题中潜热项与对流项同量级（$L j_w\approx 2.2\ \mathrm{kW/m^2}$ vs $h\Delta T\approx 0.6$–$1.0\ \mathrm{kW/m^2}$），
是"预热平衡阶段"温度曲线的决定性因素。

**约定 D5（温度单位）**：所有随温度变化的经验式（含 $e^{-3850/T}$）中 $T$ 一律用 **K**；$T_{[K]}=T_{[^\circ C]}+273.15$。

**约定 D6（输出基准）**：题目要求的"到药材中心的距离"，
- 问题 1/2/3：药材不收缩，直接是几何半径 $r=0,0.1,\dots,2.0$ cm；
- 问题 4：药材收缩，$r$ 取**当前构形**（当前半径 $R(t)$）下的物理距离，
  输出网格为 $r\in[0,\min(2.0,R(t))]$，网格随 $R(t)$ 收缩；模板列名"药材表面"取 $r=R(t)$。

## 4. 数值方法约定

1. **空间**：有限体积法，$N$ 个均匀控制体（问题 4 在 $\xi=r/R(t)$ 参考坐标下均匀）。
   网格数默认 $N=200$；收敛性研究覆盖 $N=50,100,200,400,800$。
2. **时间**：向后欧拉（隐式，L-稳定）；Newton 迭代解非线性方程组，残差绝对容差 $10^{-10}$。
   时间步默认 $\Delta t=1$ s（问题 1/3）与自适应（问题 2/4）。
3. **边界**：表面用 Robin（第三类）条件，**不要**用显式外推；$r=0$ 用对称性（有限体积下自动满足零通量）。
4. **输出**：内部解在采样时刻**线性插值**到 0.1 cm 网格；采样时刻与题目要求严格一致。
5. **每个数值结果必须能追溯到**：脚本 + 参数 JSON + 运行日志（含 hostname、代码 md5、git commit）。

## 5. 质量门（Definition of Done）

一个结果只有在**同时**满足下列条件时才允许写进论文：

- [ ] **V1 解析解验证**：线性化（常系数、线性边界）极限下与 Bessel 级数解析解误差 $\le 10^{-4}$ 相对量级。
- [ ] **V2 空间收敛**：$N$ 加倍时误差按 $\gtrsim 1.9$ 阶下降（对数斜率检验）。
- [ ] **V3 时间收敛**：$\Delta t$ 减半时误差按 $\gtrsim 0.9$ 阶下降。
- [ ] **V4 守恒审计**：水量、能量收支与边界通量积分闭合，相对残差 $\le 10^{-6}$。
- [ ] **V5 物理检查**：单调性、上下界（$0\le C$，$T$ 介于初值与湿球温度之间）、对称性、量级合理性。
- [ ] **V6 参数敏感性**：关键假设（$h_m$ 驱动势、外推段温湿度、$\rho_d$、相变切换时刻）已做扰动并给出结论。
