# 论文格式与写作约定

普通文字修改集中在 `sections/`，全篇字体、间距与标题设置集中于 `main.tex`。每次修改后运行 `bash paper/build.sh`，并检查 PDF 实际页面。

## 文稿结构

摘要已覆盖四问；第二章分别说明问题一至四的建模思路；第五章包含模型、推导、算法和结果；第六章为评价与改进；附录 A 按四题统一说明文件结构、数据来源与复现入口，并单列六份正式测试原始日志及计时来源。正式测试表格已填写题干要求的四项指标，计时依据可逐项追溯；9 条参考文献已核实并按正文首次引用顺序排列。新增引用须先核对来源，再同步顺序，核对记录见 `references_核对说明.md`。

摘要限一页，电子版首页为摘要，正文不插入目录。电子材料要求与页数、匿名等约束以 `reference/论文格式规范2026.doc` 为准。

## 字体与图表

- 中文强调使用 `{\heiti 关键词}`，与摘要的常规黑体保持同一字重。中文 `\textbf` 已统一映射；不要增加仿粗或另设中文字体。`\heiti` 是声明，花括号应包住整段声明和文字。
- 中文正文使用自带宋体，西文为 Times，数学字体及图内数学标注沿用当前配置。Windows 的黑体回退使用 `fonts/simhei.ttf`。正文行距系数为 1.18，摘要为 1.32。策略名 `grid`、`joint`、`compact` 等用正体；速度档实验仅保留在历史附件中，不纳入本版正文比较。
- 图题在图下、表题在表上，题注宋体不额外加粗；表格用 `booktabs` 三线表。符号表可跨页续排。
- 一般图表使用 `[!htbp]`，不要为了固定位置连续使用 `[H]`、`samepage` 或强制换页。编译后检查图文距离和页底留白。
- 正文图片只保留实际采用的格式。问题一、二为 PNG，问题三、四为 PDF；本次重绘的问题三、四结果图在附件中另存高清 PNG。图片来源及生成入口见 `figures/README.md`。
- 图要辅助解释几何构造和推导；相应文字使用 `\cref{fig:...}(a)` 等引用子图。放大的角度或比例必须说明。

## 公式与语言

公式使用 LaTeX，中文放入 `\text{...}`；公式、图表交叉引用使用 `\label` 与 `\cref`，不手写编号。新增主要符号同步更新表一，临时符号在首次出现时说明；同一概念保持同一字母。

正文用“问题一”至“问题四”，避免 Q1/Q2 等工程标签；真实文件路径、代码标识例外。保持图内名称、表格策略和正文一致。不要将策略配置名中的数字解释为真实清除率保证。

离线数值须可追溯至 `../attachments/Qn/DATA_SOURCES.md` 所列的输入、计算和结果；正式测试数值、原始日志与起止时间见 `../attachments/formal-tests/`。正式表格按题干要求列四项指标，平均定位清除时间按总时间除以清除数计算，程序运行时间按系统历史记录的起止时间差计算，时间戳显示精度为 1 s。新算法试验与原论文数据分别记录；使用新结果后同步统计、图册、论文表格及来源说明。附录源码直接读取评审包，不粘贴第二份代码。

## 编译检查

```bash
bash paper/build.sh
python3 paper/maintain.py check
```

检查缺字、错误、失效引用、图表溢出及大块留白。Tectonic/XeLaTeX 可能因平台字体产生正常警告；最终以成功编译和页面目视检查为准。清理编译中间文件可运行 `bash paper/build.sh clean`，保留 `main.pdf`。
