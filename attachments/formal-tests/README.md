表中清除数由测试者提供。六份日志的公开头部均标记为正式行为日志（`formal_behavior_log`），其问题编号、正式测试序号和案例编码已与上表逐一核对。

`results.csv` 汇总六次正式测试的数据及日志对应关系。测试者确认所提供的时间为**总定位清除时间**，据此以“总定位清除时间 ÷ 清除数”计算平均定位清除时间，使用十进制定点运算并四舍五入至小数点后三位，单位均为秒。

**程序运行时间**取自官方历史日志界面中各次正式测试的开始与结束时间戳之差。起止时间由测试者提供的系统界面记录转录，并按问题编号、正式测试序号和案例编码对应。界面时间戳显示到秒，故运行时间以整秒记录，不推定亚秒精度；开始、结束时间沿用界面显示的日期和时间，未附加界面未声明的时区。此项记录程序运行的实际耗时，与总定位清除时间、平均定位清除时间分别列示。

| 数据列 | 含义与来源 |
| --- | --- |
| `problem_no`、`formal_index`、`case_code` | 问题编号、正式测试序号、案例编码；已与日志公开头部核对 |
| `cleared_count` | 测试者提供的清除数 |
| `total_locating_clearing_time_s` | 测试者提供并确认口径的总定位清除时间，单位秒 |
| `average_locating_clearing_time_s` | 总定位清除时间除以清除数，保留三位小数，单位秒 |
| `program_runtime_s` | 官方历史日志界面中结束时间减去开始时间，单位秒，精度沿用界面显示 |
| `program_started_at`、`program_ended_at` | 官方历史日志界面显示的开始、结束时间，格式为 `YYYY-MM-DD HH:MM:SS`，不附加时区 |
| `log_file`、`log_sha256` | 对应原始日志文件名与文件内容的 SHA-256 |

日志使用 `JMBFLOG1` 二进制封装，公开元数据之后的行为数据经过压缩和加密。公开头部可核验上述案例对应关系，不包含清除数、计时结果、完整动作、结束状态或源总数；本地归档检查未解密行为数据，也未据此判定是否全部清除。汇总表中的清除数与总定位清除时间来源于测试者提供的结果，未从加密日志独立提取。原始日志用于官方核验，不能改名、重写、转换格式或用自行生成的日志替代。

`SHA256SUMS.txt` 记录六份原始日志的 SHA-256。日志移动前后逐一校验，校验值均一致。在本目录可用以下命令复核文件内容：

```sh
shasum -a 256 -c SHA256SUMS.txt
```

本目录与 `Q1/` 至 `Q4/` 的离线算法、仿真数据及复现入口并列保存；正式测试日志与离线仿真记录分别标识。
