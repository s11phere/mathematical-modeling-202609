## 参数、字段与统计含义

首测点为原点、示向度为 0°，长度单位为 m。理论网格步长 15 m，横坐标从 -500 至 1795 m，
纵坐标从 -1800 至 1800 m，排除纵坐标为零的无定义行；源位积分在 0 至 1500 m 上取
200 个中点，以距离成比例的面积先验加权。CSV 字段 `a,b` 为第二检测点坐标，`d_m` 为期望直径。

数值网格以 1800 m 靶区半径生成，步长 30 m，保留 11168 个候选点；`mask_radius=60`
是靠近第一测点的小圆排除半径。首条射线上源距为 5 至 1500 m，共 300 个点，
面积先验权重与源距成正比。误差平均使用 200 组误差抽样，固定种子 20260913，
测向半误差角为 1°。参数以 `results/p2_grid_report.json` 和原始程序为准。

| 数值 CSV 字段 | 含义 |
| --- | --- |
| `x_m,y_m,r_m,phi_deg` | 第二检测点的直角坐标、极径和极角。 |
| `E_diam_given_detectable_m` | 对满足接收及有限交会条件的源位重新归一后计算的条件期望，正文的主要比较量。 |
| `p_detectable,cov_weight,n_ok` | 同时满足接收与有限几何条件的源位权重比例、权重和、有效源位数。 |
| `Dmin_m,Dmax_m` | 有效源位中交会区域直径的最小值、最大值。 |
| `E_diam_err_given_detectable_m` | 同时对固定抽样测向误差平均后的条件期望，补充图册第 4 页。 |
| `E_diam_mixed_mm,E_diam_err_mixed_m` | 未按有效源位权重重新归一的加权贡献；前一列后缀为历史命名，数值单位仍为 m。不能与条件期望混用。 |
| `usable,near_axis_unusable_band` | 正文绘图、寻优使用的有效标记及高值区域标记；高值阈值为有限期望中位数的 10 倍。 |

没有有效样本时条件期望为 `nan`，其加权贡献为 0；这个 0 不表示该点定位效果最好。
补充图册保留原始网格的有限高值，色阶到 1000 m 后饱和，数值本身未截断或改写。
理论解析式与严格交会计算在近似条件、接收筛选等方面有区别，比较应限于共同可比区域。
